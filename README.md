## 📦 功能模块

### 商城前台（买家视角）
- **商品大厅** — 10 个核心 SKU，卡片式陈列，支持分类筛选与关键词搜索
- **商品详情** — 规格 / 品牌 / 库存 / 售价，一键加入购物车
- **购物车** — 增减数量、删除、清空，实时计算金额
- **结算下单** — 满 199 免运费、满 1000 减 3%，生成订单并回写后台
- **我的订单** — 查看历史下单记录与状态

### 运营后台（管理视角）
- **数据看板** — GMV / 利润 / 销量 / 抽佣四大 KPI，每日直播 GMV 折线图、单品销量 Top10、好评率环图、业务待办、达人漏斗
- **商品管理** — 商品增删改查，抽成比例、成本价、在架库存维护
- **库存管理** — 入库 / 出库登记、低库存自动预警（在架 = 入库 + 调整 − 出库）
- **订单管理** — B 端订单状态流转（进行中 → 已完成 / 退单 / 已取消）、前台商城订单同步查看
- **直播运营** — 10 场直播场次，达人、平台、商品、场次产出
- **利润分析** — 单品利润表（GMV / 抽佣 / 运营成本 / 利润），支持 **导出 CSV**
- **合规自检** — 极限词规则引擎，28 条词库实时扫描命中并给出替换建议
- **达人管理** — 40 位达人池，四阶段漏斗（已建联 → 已寄样 → 已挂车 → 已出单）
- **销售明细** — 24 条销售流水，含退款标记
- **系统设置** — 低库存阈值、主题切换（浅色 / 深色）、数据导出、演示数据重置

## 🗂 数据来源与口径

数据文件位于 `data/`，**与成果包逐行对齐**：

| 文件 | 内容 | 记录数 |
|:--|:--|:--|
| `products.json` | 商品主数据 | 10 |
| `profit.json` | 单品利润表 | 10 |
| `sales-detail.json` | 销售明细记录 | 24 |
| `orders.json` | B 端订单创建 | 15 |
| `talents.json` | 达人数据列表 | 40 |
| `inventory-in.json` | 样品入库管理 | 16 |
| `inventory-out.json` | 样品出库管理 | 15 |
| `live-sessions.json` | 直播策划大师 | 10 |
| `compliance.json` | 极限词智能自检 | 28 词 + 5 审核记录 |
| `manifest.json` | 数据概况元信息 | 25 表 / 895 记录 / 7 模块 |

### 计算口径

```
GMV      = 销量 × 单价
抽佣     = GMV × 抽成比例
利润     = GMV − 抽佣 − 直播运营成本
在架库存 = 入库数量 + 调整数量 − 累计出库
```

### 数据一致性说明

- **库存**：16 条入库记录全部满足上式，`调整数量` 字段用于解释成果包中存在的负库存 / 手工调整。
- **利润表**：10 条中 9 条严格满足 `GMV = 销量 × 单价`；
  - `P004 际越三合一冲锋衣` 为浮点精度差异（`256799.99999999997` vs `256800`），可忽略；
  - `P010 Phone 15 Pro Max` 的 `GMV` 按**成果包原值 `170000`** 保留（非 `7000 × 20 = 140000`），商品描述中已标注为「演示口径商品，价格按成果包单品利润表记录」。

## 🛠 技术实现

| 项 | 说明 |
|:--|:--|
| 架构 | 原生 ES6 + Hash 路由（`#/dashboard`、`#/shop`…），单页应用 |
| 依赖 | **零依赖**，无框架、无构建、无 npm |
| 持久化 | `localStorage` 保存购物车、商城订单、设置；「重置演示数据」一键还原 |
| 图表 | 手写 SVG（折线图 / 环图），不引图表库 |
| 主题 | CSS 变量驱动，浅色 / 深色一键切换 |
| 视觉 | 深色侧边栏 + 浅色内容区；遵循中文电商惯例 **涨红跌绿**（红 `#dc2626` / 绿 `#16a34a`） |
| 加载策略 | 优先 `fetch` 加载 `data/*.json`；失败时回退内联种子数据，保证 `file://` 也能运行 |

### 文件结构

```
ai-ecom-sales-system/
├── index.html            # 外壳 + 设计系统 + 登录页 + 应用框架
├── app.js                # 核心：状态、派生数据、图表、极限词引擎、购物车
├── views-shop.js         # 前台视图（看板 / 商城 / 详情 / 购物车 / 结算 / 我的订单）
├── views-admin.js        # 后台视图（商品 / 库存 / 订单 / 直播 / 利润 / 合规 / 达人 / 销售 / 设置）
├── boot.js               # 启动、鉴权、路由、主题、事件绑定
├── data/                 # 10 个 JSON 数据文件（25 张业务表）
├── .github/workflows/pages.yml   # GitHub Pages 自动部署工作流
└── .nojekyll             # 允许以下划线开头的静态资源
```

## 💻 本地运行

因使用 `fetch` 加载数据，建议通过 HTTP 服务访问（直接双击 `index.html` 亦可运行，但会走内联兜底数据）：

```bash
# 方式一：Python
python3 -m http.server 8080

# 方式二：Node
npx http-server -p 8080
```

打开 <http://localhost:8080>，使用上表任一账号登录。
